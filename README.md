# Mi Secretaria IA

Secretaria digital personal: chat, tareas, proyectos, memoria, prioridades y agenda. Dos espacios separados (personal y profesional).

La aplicación se está construyendo sobre Next.js, Supabase y OpenAI. Consulta los pasos de configuración y despliegue más abajo cuando se añadan al repositorio.

**Privacidad:** no se almacenan datos de pacientes ni secretos en GitHub.
